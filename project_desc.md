# Collage Card Maker

A static web app for designing printable A4 photo cards. It lets you build a collage on one half of an A4 sheet, leaving the other half blank so the result can be printed and folded into a card.

The editor supports portrait and landscape A4 layouts, drag-and-drop photo importing, automatic tessellated collage layouts, and manual per-photo crop control with mouse-wheel zoom and drag-to-pan positioning. It includes multiple layout styles, mixing square, portrait, and landscape photo holders so different sets of images can be arranged cleanly.

Exports are generated client-side as high-resolution PNG files suitable for A4 printing. The app is built as a static Vite project and can be deployed to GitHub Pages.
